Wishlist Issues

This page lists all issues of the Rucio repositories that have been closed with the wishlist label. As described in the issue management guideline, these are issues of potential value that are not planned for the next twelve months. Wishlisted issues are revisited regularly and can be re-opened when there is both interest and capacity from component leads. The Wishlisted column shows when the wishlist label was last added to an issue.

This list is refreshed automatically whenever the documentation is built. You can also view it directly on GitHub.
